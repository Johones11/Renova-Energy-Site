# Projeto Renova Energy

Bem-vindo ao projeto **Renova Energy**, uma plataforma moderna, dinâmica e responsiva para apresentar soluções de energia solar e elétrica de alta performance em Moçambique.

## 🚀 Funcionalidades Principais
- **Single Page Application (SPA):** Navegação fluida sem recarregar a página.
- **Design Moderno:** Utilização de glassmorphism, parallax e animações elegantes de scroll (`reveal-up`).
- **Multilíngue (PT / EN):** Sistema de idiomas global integrado, permitindo a transição em tempo real entre Português e Inglês com a seleção persistindo no `localStorage`.
- **Modo Escuro (Dark Mode):** Sistema dinâmico e polido de transição entre temas claro e escuro, também salvo no `localStorage`.
- **Responsive Design:** Totalmente adaptado para dispositivos móveis, tablets e desktops.

## 🛠️ Tecnologias Utilizadas
- HTML5 (Semântico)
- CSS3 (Variáveis globais, CSS Grid, Flexbox, Animações)
- JavaScript (Vanilla JS para manipulação de DOM, SPA, e Lógica de Temas/Idiomas)

## 📁 Estrutura do Projeto
```text
/
├── index.html           # Página principal (SPA)

```
