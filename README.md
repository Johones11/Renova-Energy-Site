# Projeto Renova Energy

Bem-vindo ao projeto **Renova Energy**, uma plataforma moderna, dinâmica e responsiva para apresentar soluções de energia solar e elétrica de alta performance em Moçambique.

🌐 **Produção:** [renovaenergy.co.mz](https://renovaenergy.co.mz) · **Deploy:** Cloudflare Pages

## 🚀 Funcionalidades Principais
- **Single Page Application (SPA):** Navegação fluida sem recarregar a página (secções via hash routing).
- **Design Corporativo Premium:** Cabeçalho flutuante estilo barra de pesquisa, hero a ocupar o topo, cartões estilo Pinterest, sombras marcadas e micro-animações elegantes.
- **Multilíngue (PT / EN):** Sistema de idiomas global integrado, com transição em tempo real e seleção persistida no `localStorage`.
- **Modo Escuro (Dark Mode):** Transição polida entre temas claro e escuro, também guardada no `localStorage`.
- **Responsive Design:** Totalmente adaptado a telemóveis, tablets e desktops, sem quebras horizontais.
- **SEO:** `robots.txt`, `sitemap.xml`, tags canónicas, Open Graph/Twitter e Schema.org (LocalBusiness).

## 🛠️ Tecnologias Utilizadas
- HTML5 (Semântico)
- CSS3 (Variáveis globais, CSS Grid, Flexbox, Masonry, Animações)
- JavaScript (Vanilla JS para manipulação de DOM, SPA, e Lógica de Temas/Idiomas)

## 📁 Estrutura do Projeto
```text
/
├── index.html           # Página principal (SPA)
├── privacidade.html     # Política de Privacidade
├── termos.html          # Termos de Uso
├── 404.html             # Página de erro personalizada (servida pelo Cloudflare Pages)
├── robots.txt           # Diretivas para motores de busca
├── sitemap.xml          # Mapa do site para indexação
├── css/
│   └── style.css        # Estilos globais e componentes
├── js/
│   ├── main.js          # Lógica principal (SPA, Theme, Lang, Forms)
│   └── translations.js  # Dicionário de traduções PT/EN
├── logotipo/            # Imagens de marca e favicons
├── imagens/             # Imagens ilustrativas
│   └── parceiros/       # Logótipos dos parceiros
├── EDITOR.md            # Guia de edição para a equipa (sem conhecimentos técnicos)
└── README.md
```
